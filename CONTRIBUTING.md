# Contributing

Thanks for looking. For now, LumenList does not accept outside contributions. Pull requests from outside Patea will be closed without review.

## Why

LumenList is built by Patea LLC and published under the AGPL-3.0 so anyone can read, run and learn from it. Patea may also offer it under other terms in the future. That is only possible while Patea holds the copyright to all of the code, so we can't merge code we didn't write.

## What you can do

- **Use it.** The AGPL-3.0 lets you run, study, change and share it, as long as you follow its terms, including sharing your changes if you run a modified version as a service. See [`LICENSE`](./LICENSE).
- **Report a security problem** privately, as [`SECURITY.md`](./SECURITY.md) describes.
- **Tell us about a bug or an idea** by email at hello@pateastudio.com.

## How this repository works

This repository mirrors each release of LumenList as one commit. Development happens in a private repository, so changes appear here when they are released, not as they are made.
